# Sales and Profit Analysis Using Excel
This project analyzes sales and profit data using Microsoft Excel.
The analysis focuses on product category performance based on sales and profit metrics.
## Tools Used
- Microsoft Excel
- Pivot Tables
- Basic statistical analysis
## Analysis Performed
- Sales summary by product category
- Profit comparison across categories
- Descriptive statistics (mean, median, minimum, maximum, standard deviation)
- Identification of sales distribution characteristics
## Key Insights
- Technology category generated the highest total sales and profit.
- Sales data is right-skewed, indicating the presence of high-value outliers.
- Median sales better represent typical transactions than the mean.
## Files
- Sales_Profit_Analysis_Excel.pptx – Presentation of analysis results
- Superstore_Sales_Data.xlsx – Dataset used for analysis
